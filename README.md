# Йўқлама тизими — 104 та ташкилот

«So‘z» ҳамда «Vatan playlisti» лойиҳалари доирасидаги театрлаштирилган шеърий-концерт
кечаси учун иштирокчиларни белгилаш тизими.

**Онлайн, бир нечта оператор бир вақтда ишлайди.** Барча белгилар GitHub'даги битта
файлга ёзилади ва 10 сонияда бир марта ҳамма қурилмада янгиланади.

## Ўрнатиш

### Осон йўл — автоматик скрипт

Компьютерда (телефон hotspot'идан!):

```
py -3 tools/deploy.py
```

Скрипт логин ва токен сўрайди (classic токен, `repo` рухсати билан), сўнг ўзи:
repo'ларни яратади, файлларни юклайди, Pages'ни ёқади. Тайёр манзилни экранга чиқаради.
Жойлашдан кейин бу токенни ўчириб юборинг — операторларга бошқа, чекланган токен берилади
(қуйида 3-қадам).

### Қўлда ўрнатиш: 3 та қадам

### 1-қадам. Сайт учун омбор (public)

1. GitHub'да янги **public** repository очинг: `yoqlama`
2. Ушбу папкадаги барча файлларни юкланг (`index.html`, `persons.js`, `photos/`)
3. **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**
4. 1–2 дақиқадан сўнг сайт очилади:
   `https://<логин>.github.io/yoqlama/`

### 2-қадам. Маълумот учун омбор (private)

Белгилар шахсий маълумотлар билан боғлиқ, шунинг учун **алоҳида ва ёпиқ** омборда сақланади.

1. Янги **private** repository очинг: `yoqlama-data`
2. Ичига `attendance.json` номли файл яратинг, мазмуни:
   ```json
   {"records":{}}
   ```
   (Add file → Create new file → номи `attendance.json` → Commit)

### 3-қадам. Токен

1. GitHub → **Settings** (профиль) → **Developer settings** →
   **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
2. Тўлдиринг:
   - **Token name:** `yoqlama`
   - **Expiration:** тадбирдан 1–2 кун кейинги сана
   - **Repository access:** *Only select repositories* → **`yoqlama-data`**
   - **Permissions → Repository permissions → Contents:** **Read and write**
3. **Generate token** → чиққан сатрни нусхалаб олинг (`github_pat_...`).
   ⚠️ У фақат бир марта кўрсатилади.

## Операторлар учун

Ҳар бир оператор ўз телефон/компьютерида:

1. `https://<логин>.github.io/yoqlama/` ни очади
2. Юқорида **Оператор** майдонига ўз исмини ёзади
3. **⚙ Созламалар** тугмасини босиб тўлдиради:
   - GitHub логин: `<логин>`
   - Repo: `yoqlama-data`
   - Path: `attendance.json`
   - Branch: `main`
   - Токен: `github_pat_...`
4. **✔ Сақлаш ва уланиш**

Юқоридаги нуқта **яшил** бўлса — ҳаммаси ишлаяпти.
Токен фақат шу браузерда сақланади, сайт кодига тушмайди.

> Токенни операторларга Telegram/почта орқали эмас, оғзаки ёки қоғозда беринг.
> Тадбир тугагач GitHub'да токенни **Revoke** қилиб қўйинг.

## Ишлатиш

- **Келди / Ўрнига вакил / Келмади** — тугмани босинг. Қайта боссангиз — белги бекор бўлади.
- **Изоҳ** — ким келгани, лавозими ёки келмаслик сабаби.
- **Қидириш** — ташкилот номи, Ф.И.О. ёки рақам бўйича.
- **📊 Ҳисобот** — умумий жадвал.
- **🖨 Чоп этиш / PDF** — Ctrl+P ойнасида *«Принтер: Сохранить как PDF»* танланг.
- **📗 Excel (CSV)** — Excel'да очиладиган файл.
- **💾 Заҳира / 📁 Юклаш** — интернет бўлмаган ҳолат учун.

### Интернет узилиб қолса

Дастур ишлашда давом этади — белгилар браузерда сақланади ва алоқа тикланиши билан
автоматик равишда серверга юборилади. Икки оператор бир вақтда белгиласа,
**энг сўнгги белги** сақланади (ҳар бир ташкилот алоҳида ҳисобланади).
